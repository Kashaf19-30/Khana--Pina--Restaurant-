🍽️ Khana Pina - Restaurant
A modern and user-friendly restaurant website built with HTML, CSS, and JavaScript.
Khana Pina provides a simple and attractive interface where users can explore food, restaurant information, special offers, and contact details.

📌 About The Project
Khana Pina is a restaurant website project created as part of my web development learning journey.

The project focuses on building a clean restaurant interface using front-end web technologies. It includes a navigation bar, hero section, food search area, promotional offers, categories, restaurant information, newsroom section, and contact section.

This project helped me practice:

HTML page structure
CSS styling and layouts
Navigation and links
Images and website assets
Responsive design concepts
JavaScript functionality
Organizing a web project into separate files
✨ Features
Attractive homepage
Food and restaurant sections
Food/restaurant search interface
Promotional offers
Food categories
